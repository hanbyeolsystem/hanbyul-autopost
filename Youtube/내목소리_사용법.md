# 광고 자동화에 내 목소리 사용하기

이 PC의 내 목소리 스튜디오에 등록한 목소리를 사용합니다. 별도 음성 API 요금은 없습니다.

## 광고 콘솔에서 대본 보내기

채널 카드의 ‘내 목소리’를 누르고 읽을 대본을 확인하세요. 분위기를 선택하고 ‘스튜디오에서 내 목소리로 만들기’를 누르면 대본과 분위기가 스튜디오에 채워집니다. 스튜디오의 생성 버튼을 누르면 WAV가 만들어집니다. 이 기능은 스튜디오가 설치된 PC에서 사용합니다.

## 사진으로 쇼츠 자동 제작

기존 쇼츠 제작 명령은 이제 내 목소리를 기본으로 넣습니다.

```powershell
python Youtube/쇼츠만들기.py --slug yecheon-office-ds925 --voice-style 활기차게
python Youtube/쇼츠만들기.py --slug yecheon-office-ds925 --voice-style 차분하게
python Youtube/쇼츠만들기.py --all --limit 3 --voice-style 기본
```

사진과 자막으로 장면을 구성하고 → 장면별 대본을 내 목소리로 생성하고 → 음성 길이에 맞춰 장면 시간을 조정하고 → 음성이 포함된 MP4와 발행용 JSON을 완성본 폴더에 저장합니다.

- 스타일: 기본 / 활기차게 / 차분하게. 스타일별 녹음이 없으면 기본 목소리에 속도·쉼·소리의 힘을 적용합니다.
- 스튜디오가 꺼져 있으면 로컬에서 자동 시작합니다.
- 생성에 실패하면 무음으로 대체하지 않고 중단합니다.
- 동일 대본·목소리·스타일은 장면 음성을 재사용합니다.
- 기존처럼 무음이 필요하면 `--no-voice`를 붙이세요.
- 확인용 영상은 `--output-dir Youtube/목소리미리보기`로 별도 생성할 수 있습니다.

## 자동 발행과의 관계

GPU 음성 생성은 이 PC에서 합니다. GitHub의 예약 발행은 이미 완성된 MP4를 올리는 단계입니다. 새 영상과 글을 검증한 뒤 기존 발행 흐름에 전달해야 합니다. 이번 연결 자체는 영상 게시나 예약 발행을 실행하지 않습니다.

원본 목소리 파일은 PC의 MyVoice 폴더에만 보관하며 광고 저장소에 복사하지 않습니다.
